# Eletromix Android

Aplicativo Android em Capacitor conectado ao mesmo PDV móvel usado no iPhone.
O APK carrega a versão publicada do Eletromix, por isso melhorias de interface e
regras de negócio passam a valer nos dois celulares sem reinstalação.

O workflow `build-mobile-apk.yml` gera um APK de teste instalável e o disponibiliza
como artefato da execução no GitHub Actions.
